## Estrutura do Sistema
O sistema foi projetado com uma interface vertical (largura restrita de 320px). A jornada do usuário consiste em um fluxo de quatro telas principais:
1. **Entrada:** Escolha dos meses do semestre
2. **Mensal:** Visualização dos dias do mês com destaque visual para agendamentos.
3. **Diário:** Blocos de 24 horas (60 minutos cada) exibindo os cartões de eventos.
4. **Adição de Tarefas:** Formulário para inserção de eventos (Título, Local, Início, Fim e tempo de trajeto) e criação de novos compromissos com **regra de exclusividade** (impede o agendamento de dois eventos no mesmo horário).
