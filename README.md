## Estrutura do Sistema
    1. **Seleção Semestral (`index.html`):** Interface para escolha dos meses, dispostos de forma semestral e selecionáveis.
    2. **Calendário Mensal (`calendario.html`):** Geração dinâmica do calendário do mês escolhido, com disposição semanal ordenada e dias selecionáveis.
    3. **Agenda Diária (`agenda.html`):** Gerenciador de eventos do dia. Permite a visualização das horas e criação de novos compromissos com **regra de exclusividade** (impede o agendamento de dois eventos no mesmo horário).
